# Olist Revenue & Customer Satisfaction Analysis

## Business Problem
Olist is a Brazilian e-commerce marketplace. This project investigates where
revenue is growing or slowing, and whether delivery performance affects
customer satisfaction.

## Questions
1. How has monthly revenue changed over time, and which months changed most?
2. Do late deliveries lead to lower review scores?
3. Which states and product categories drive the most revenue?

## Dataset
Brazilian E-Commerce Public Dataset by Olist (Kaggle), 9 related tables,
about 100k orders from 2016 to 2018.

## Tools
Python (data loading), SQLite (analysis), SQL (window functions, CTEs),
Tableau Public / Power BI (dashboard)
